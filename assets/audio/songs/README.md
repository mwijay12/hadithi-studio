# Nyimbo za Watoto

Weka faili za nyimbo hapa. Hakuna msimbo wa kubadilisha.

## Jina la faili
```
01_kitendawili.mp3
02_safari_ya_wanyama.mp3
```
- Nambari ya mwanzo = mpangilio kwenye ukurasa.
- `_` hubadilishwa kuwa nafasi; jina linakuwa kichwa cha wimbo.
- `.mp3`, `.m4a`, `.wav` zinakubaliwa.

## Kichwa cha lugha mbili (hiari)
Weka faili ya `.json` yenye jina lile lile:
```json

```
